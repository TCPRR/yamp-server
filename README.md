# yampd

The official server set for the YAMP Protocol, a decentralized server-and-DM chat protocol

</div>

## Server Features

- Full implementation of YAMP
- YAMP-HTTP baked into the binary
- Fast C implementation
- Supports mostly the same types/structs as Yampen
- The only implementation (so far) aside from the incomplete Yamp.Net project by Lanternoric
